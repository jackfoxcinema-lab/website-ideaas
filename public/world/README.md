# World images

Images for world entries. Reference them from an entry's frontmatter:

```yaml
image: "/world/glasshouse.jpg"
```

Landscape works best — the entry page crops to 3:2, and the index shows a
small square thumbnail. Around 1600px wide is plenty.

Photos, scans, drawings, screenshots of a video frame: anything that makes
the place feel real is fair game. An entry without one is fine too.
